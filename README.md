## Background

Honorific expressions appear frequently in classical Islamic texts, yet the availability of high-quality, freely usable glyphs for these expressions remains limited. While the need is real and widespread, only a handful of fonts provide reasonable coverage, and each comes with its own constraints.

Fonts such as Scheherazade New provide solid Unicode coverage under an open license, but their honorific glyphs do not reflect the visual forms and compositions found in classical Arabic printing traditions—the kind seen in editions from publishers like Dar al-Minhaj, where honorifics are rendered with the calligraphic refinement of traditional Thuluth/Naskh. Other fonts, such as Omar Naskh, offer refined glyphs but under proprietary licenses. The KFGQPC Arabic symbol fonts come closest to the established printing standard, with elegant visual forms and compositions, but they too carry a restrictive license, cannot be freely redistributed or modified, and do not cover the full range of honorific expressions found across different Islamic scholarly traditions.

This collection addresses that gap. The artwork was handcrafted in Inkscape, while the glyphs were derived from forms generated in Kaleam and Kelk, drawing inspiration from the visual forms and compositions found in KFGQPC Arabic Symbol and in classical Arabic typography. The collection is released under the CC BY 4.0, making it freely available for use in any project—digital, print, educational, commercial, or otherwise.

## Contents

| Path | Description |
|------|-------------|
| `svg/` | Individual SVG files, one per glyph (union path) |
| `png/` | Individual PNG files, one per glyph (black on transparent) |
| `specimen/specimen-sheet.png` | Full specimen sheet (all 61 glyphs) |
| `specimen/specimen-sheet.pdf` | Specimen sheet in PDF format |
| `specimen/source.svg` | Source file with all glyphs (Inkscape, grouped) |

---

## File naming

Files follow the pattern `{prefix}-{transliteration}.svg`, where prefix indicates the honorific group:

| Prefix | Group |
|--------|-------|
| `alh` | after the name of Allah |
| `sal` | sallallahu |
| `slt` | as-salatu was-salam |
| `slm` | as-salam |
| `slw` | salawatullah |
| `rad` | radiyallahu |
| `rhm` | rahimahullah |
| `rmt` | rahmatullah |
| `qds` | qaddasa |
| `hfz` | hafizahullah |
| `mix` | mixed |

> **Note on USV:** Unicode Scalar Values listed above are based on the honorific encoding in [Scheherazade New](https://software.sil.org/scheherazade/honorifics/) and the [Unicode Arabic Honorifics proposal](https://www.unicode.org/L2/L2019/19289r-arabic-honorifics.pdf). Some glyphs use codepoints from the Arabic Extended-C block (U+10ED0–U+10EFF), added in Unicode 15.1. Glyphs marked `—` do not yet have assigned Unicode codepoints and are candidates for Private Use Area (PUA) encoding. A proposal to contribute this artwork to Scheherazade New has been submitted—see [issue #15](https://github.com/silnrsi/font-scheherazade/issues/15).
